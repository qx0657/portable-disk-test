# 移动硬盘测试

原生 macOS 外接硬盘信息与 SMART 工具。插入移动硬盘即可查看容量、分区、温度、累计通电和读写量；支持多设备，以闪迪 SanDisk 移动 SSD 为重点验证对象。

当前版本 **1.2.0**。使用 SwiftUI / AppKit，在当前 Mac 上读取和保存数据，无需账号或服务器。测速使用独立的 [AmorphousDiskMark](https://apps.apple.com/app/amorphousdiskmark/id1168254295)，本应用提供参数建议、打开工具并导入成绩。

## 功能

- **多设备发现**：识别 USB / 雷雳外接物理磁盘及其卷，排除 Mac 内置磁盘和磁盘镜像。
- **健康概览**：温度、寿命消耗、累计读写、通电时间与次数；区分故障、权限不足、不支持和部分日志读取失败。
- **SMART 详情**：统一的 ATA / NVMe 指标、厂商属性、原始文本和 JSON，支持搜索与复制。
- **有来源的型号信息**：主标题保留真实 Model；系列和料号分别注明设备报告、官方资料匹配、标签确认或手动确认。
- **料号补充**：手动填写或本地识别标签照片，确认后按物理设备记住。
- **测速记录**：建议参数、打开第三方工具、导入文字成绩并确认归属；每盘最多保留 30 份成绩。
- **本地历史和报告**：每盘最近 180 次温度采样，可导出设备信息、SMART 和测速记录。

缺失数据会显示“未提供”，不会填成零。SMART 通过或寿命消耗 0% 不能单独证明设备全新，也不能保证剩余寿命。

## 系统与兼容性

| 项目 | 当前情况 |
| --- | --- |
| 系统目标 | macOS 14 及以上 |
| 构建工具 | Swift 5.9+、macOS SDK、Command Line Tools；测试不依赖完整 Xcode 插件 |
| 已验证架构 | Apple Silicon；脚本按宿主架构编译，不生成通用二进制 |
| 实机环境 | Apple Silicon Mac mini、macOS 27.0.1 |
| 已验证设备 | SanDisk Extreme Portable SSD E60 1 TB（USB / ATA）、Extreme PRO with USB4 E82 4 TB（USB4 / NVMe） |
| 其他品牌 | 可显示系统能发现的外接硬盘；SMART 是否可读取取决于系统、设备和桥接芯片 |
| 文件系统 | 已用 ExFAT 实盘验证；APFS 容器与卷解析有检查，尚未完成外接 APFS 实盘验证 |

应用不自行安装驱动或提权。有些 USB 转接盒无法通过 macOS 提供 SMART，此时仍可查看基本信息。当前构建使用本地 ad-hoc 签名，尚未提供 Developer ID 签名与公证。

## 构建并运行

仓库提供源码和构建脚本。先准备 macOS Command Line Tools，再执行：

```bash
git clone https://github.com/qx0657/portable-disk-test.git
cd portable-disk-test
swift run DiskCoreChecks
bash scripts/build.sh
open "outputs/移动硬盘测试.app"
```

首次构建会下载并校验固定版本 **smartmontools 7.5** 源码，在项目 `work/` 中编译 `smartctl`，将读取组件、许可证和对应源码一起放入应用。构建过程需要联网，不修改系统安装的 smartmontools。

安装到当前用户的应用目录：

```bash
bash scripts/build.sh --install
open "$HOME/Applications/移动硬盘测试.app"
```

安装前应退出旧版，并按需要备份本地记录。`--install` 会替换相同 bundle identifier 的应用，不会自动生成升级备份。更多命令和打包方式见[开发说明](docs/development.md)。

## 使用流程

### 查看设备与 SMART

连接硬盘后在左侧选择目标设备。“概览”显示容量、卷、温度、使用程度和身份；“SMART”展示具体指标、厂商属性及原始输出。

默认约每 3 秒检查设备列表，SMART 约每 30 秒重读；“重新扫描”（⌘R）立即重读。关闭自动更新后仍可手动扫描，挂载和卸载通知也会更新设备列表。

温度曲线是本应用在当前 Mac 上采集的近期记录，并非硬盘自带的完整历史。E60 部分扩展日志不可读时，成功读取的指标仍会保留，不会仅因此判为坏盘。

### 补充完整料号

入口：**概览 → 设备信息 → 补充料号…**。

| 来源 | 含义 |
| --- | --- |
| 设备报告 | 实际返回的 Model 中直接包含系列代码或完整料号 |
| 官方资料匹配 | 通过已核实的厂商目录与产品资料确认系列，不据此拼接完整料号 |
| 标签确认 | 从标签照片识别完整代码，并由用户核对保存 |
| 手动确认 | 用户填写并确认的完整料号 |

目前 E82 有核实过的官方目录规则；E60 的旧硬件 ID 不在该目录中，默认保持“未确认”。完整料号缺失时显示“设备未提供”，不按名称、容量或接口补全。

照片支持 PNG / JPEG / HEIC / TIFF，通过本地 Apple Vision 识别。当前识别聚焦闪迪 `SDSSDE…` 完整代码，其他品牌可手动填写。多个结果需要选择，模糊的 O/0 等字符不会自动替换；所有结果都须“确认并保存”。出现系列冲突时要求再次核对。

补充信息不覆盖原始 Model。缺少唯一物理序列号、身份重复、目标已断开或扫描失败时禁止保存。照片不上传、不保存副本。具体边界见[型号识别说明](docs/model-identification.md)。

### 测速与导入

本应用没有内置测速引擎，流程如下：

1. 在“测速”页选择目标卷和测速目的，查看建议参数。
2. 未安装 AmorphousDiskMark 时，点击“在 App Store 获取测速工具”自行安装。
3. 安装后回到本应用，点击“打开 AmorphousDiskMark”；若状态没刷新，重新扫描。
4. 在 AmorphousDiskMark 中手动选择目标卷、次数和文件大小，点击 **All**。
5. 测完在其窗口按 **⌘C**，回到本应用选择“导入成绩 → 从剪贴板导入”；也支持 UTF-8 文本文件。
6. 核对成绩型号、卷名及目标硬盘，点击“确认并保存”。

“保存到”选择的是**成绩关联的设备**，实际记录保存在当前 Mac，不会在移动硬盘内创建成绩文件。成绩不含可靠序列号，所以必须由用户确认归属。

当前未实现可可靠指定第三方工具目标卷和参数的启动接口，不自动点击测速按钮；剪贴板只在点击导入时读取。

参数随快速检查、日常对比、较大工作集而改变，并非所有硬盘固定 3 次 × 4 GiB。较大文件仍可能落在 SSD 缓存内，不能证明已测得缓存耗尽后的持续速度。前后或跨盘比较应手动统一参数；实际写入量可能大于工作文件大小。

### 导出报告

点击“导出报告”（⌘E），自行选择保存位置。报告包含设备信息、SMART 原文、补充料号和已关联的测速成绩。

想在移动硬盘里看到报告文件，需要在导出时将目标位置选到该盘。报告可能包含序列号、设备标识、卷名和挂载路径，对外分享前应先脱敏。

## 数据保存在哪里

默认保存在**当前 Mac 用户的资料目录**：

```text
~/Library/Application Support/PortableDiskTest/
├── history.json        # 首次记录时间、温度采样、测速成绩
└── device-labels.json  # 已确认料号、来源和确认时间
```

`device-labels.json` 在首次确认保存补充信息后创建；自动更新偏好由系统 UserDefaults 保存。

- 历史优先按序列号关联，缺失时使用唯一卷 UUID；身份不可靠或重复时不跨会话保存历史和测速成绩。
- 补充料号仅按唯一物理序列号绑定，不使用设备号、卷名或卷 UUID。
- 换设备号、卷改名不改变物理序列号关联；换一台 Mac，本地记录不会随硬盘自动同步。
- 备份或迁移时先退出应用，再复制整个资料目录。删除 `.app` 不会自动删除这些记录。
- 采集和照片识别不上传数据；构建下载依赖、以及用户主动打开商店或官网链接会访问网络。

移动盘里的 **SANDISK Vault** 是闪迪的加密保险箱，与本应用的本地记录无关。本应用不会创建或修改它。
